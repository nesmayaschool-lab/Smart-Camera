# الكاميرا الذكية

هذه نسخة العمل الجديدة المستقلة من مشروع Auto Camera.

## الهوية
- الاسم الظاهر داخل التطبيق: الكاميرا الذكية
- اسم المستودع: Smart-Camera
- المستودع القديم `auto-camera` لم يتم تعديله.

## الملفات
- `index.html`: صفحة التطبيق الرئيسية، مبنية على نسخة الإصلاح المتاحة `index_fixed.html`.
- `manifest.json`: إعدادات تثبيت التطبيق كتطبيق ويب تقدمي (PWA).
- `sw.js`: عامل الخدمة والتخزين المؤقت.
- `icon-192.png` و`icon-512.png`: أيقونات النسخة الجديدة.

## النشر
ارفع محتويات هذا المجلد إلى جذر المستودع الجديد `Smart-Camera`، مع جعل `index.html` في الجذر.
لا ترفع الملف القديم `index_original.html` مكان `index.html`.

## ملاحظات الاختبار
- تم فحص صياغة JavaScript المضمنة وفحص صحة JSON للـ manifest.
- لم يتم إجراء اختبار تشغيل فعلي للكاميرا أو إزالة الخلفية على هاتف حقيقي.
- يتطلب تشغيل الكاميرا وإزالة الخلفية اتصالاً بالإنترنت لتحميل مكتبات ونماذج الطرف الثالث، كما يتطلب نشر الموقع عبر HTTPS أو localhost للسماح بوصول الكاميرا.
- الأيقونات المرفقة صُنعت للهوية الجديدة ولا تمثل الأيقونات الأصلية للمشروع القديم.
